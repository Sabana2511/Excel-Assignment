# 📊 Data Exploration By Using Excel

## 📌 Project Overview

This project demonstrates the use of Microsoft Excel for data exploration and analysis. 
The dataset contains product-related information, including product names, brands, prices, quantities and categories.
Various Excel functions were used to extract meaningful insights from the data.

---

## 📂 Dataset Details

The dataset includes the following fields:

- Product ID
- Product Name
- Brand Name
- Price ($)
- Quantity
- Category
- Price Range
- Day
- Country Code
- Month

---

## 🎯 Objectives

- Analyze product data using Excel formulas.
- Calculate summary statistics.
- Identify minimum and maximum values.
- Perform category-based analysis.
- Apply Logical function and conditional functions for business insights.

---

## 🛠 Functions Used

### 1. SUM
Calculates the total price of all products.

**Result:** 10,100

### 2. COUNTA
Counts the total number of products.

**Result:** 34

### 3. AVERAGE
Calculates the average product price.

**Result:** 297

### 4. MIN
Finds the lowest product price.

**Result:** 30

### 5. MAX
Finds the highest product price.

**Result:** 1000

### 6. SUMIF
Calculates the total price of products in the Electronics category.

**Result:** 8,050

### 7. COUNTIF
Counts products priced below $100.

**Result:** 11

### 8. IF FUNCTION
Categorize the products based on their price.

### 9. Text Formatting – LEFT, RIGHT, MID
Extracts information from the Product ID column.

---

## 📈 Key Insights

- Total products analyzed: **34**
- Total price value: **$10,100**
- Average product price: **$297**
- Lowest price: **$30**
- Highest price: **$1,000**
- Electronics category contributes the highest total price value.
- **11** products are priced below $100.
